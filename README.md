# ⚖️ 재판 시스템 사용 안내

디스코드 서버 내 **재판 시스템**의 이용 방법 및 진행 절차 안내 문서입니다.

---

## 📋 고소 방법

1. 재판소 채널 내 `📋 고소장 접수` 버튼을 클릭합니다.
2. 피고인을 선택합니다.
3. 죄목을 입력합니다. (**최소 5자 이상**)

---

## 🔄 재판 진행 순서

재판은 총 11단계로 진행됩니다.

| 단계 | 진행 항목 | 제한 시간 및 내용 |
| :--- | :--- | :--- |
| **1단계** | 배심원 모집 | **120초** (3명 ~ 7명 모집) |
| **2단계** | 검사·변호사 모집 | **60초** (미모집 시 AI 자동 배정) |
| **3단계** | 원고 진술 | **180초** (🔇 정숙 모드 적용) |
| **4단계** | 피고 진술 | **180초** (🔇 정숙 모드 적용) |
| **5단계** | 증거 제출 | **300초** (텍스트 및 이미지 제출 가능) |
| **6단계** | 자유 공방 | **300초** (전원 자유 발언 가능) |
| **7단계** | 원고 최종 변론 | **180초** |
| **8단계** | 피고 최종 변론 | **180초** |
| **9단계** | 배심원 비공개 투표 | **120초** |
| **10단계** | 판결 | **배심원 투표 50% + AI 심사 50%** 반영 |
| **11단계** | 닉네임 결정 | **120초** (승소자가 닉네임 지정, AI가 적용 기간 확정) |

---

## 🏷️ 형벌 및 제재 규정

* **패소자 닉네임 강제 변경:** 승소자가 원하는 닉네임으로 변경할 수 있습니다.
* **형벌 적용 기간:** AI가 죄질 및 판결 내용에 따라 **1일 ~ 30일** 사이로 확정합니다. *(임의 변경 불가)*
* **닉네임 우회 시도:** 형벌 기간 중 닉네임을 임의로 변경할 경우 **+3일 연장** 처리되며, 형벌 닉네임이 자동 재적용됩니다.
* **형벌 만료:** 설정된 기간이 지나면 원래 사용하던 닉네임으로 **자동 복구**됩니다.

---

## 📌 패널 버튼 안내

재판소 패널 하단에서 이용할 수 있는 버튼 기능 목록입니다.

* `📋 고소장 접수` — 새로운 재판을 청구합니다.
* `📚 판례 조회` — 이전 재판 판결 기록을 확인합니다.
* `🏆 랭킹` — 승소/패소 등 재판 관련 랭킹을 확인합니다.
* `🔍 내 전과` — 본인의 피소 및 유죄 판결 이력을 조회합니다.
* `⛓️ 내 닉네임 형벌` — 현재 적용 중인 닉네임 형벌 잔여 기간을 확인합니다.

---

## 💻 슬래시 명령어 (`/`)

| 명령어 | Description | 권한 |
| :--- | :--- | :--- |
| `/전과조회` | 특정 멤버의 전과 및 판결 이력을 확인합니다. | 전체 |
| `/증인소환` | 진행 중인 재판에 증인을 소환합니다. | 재판 참여자 |
| `/항소` | 종료된 사건에 대해 항소를 진행합니다. **(패소 시 형량 1.5배 가중)** | 패소자 |
| `/강제종료` | 진행 중인 재판을 즉시 강제 종료합니다. | 관리자 |
| `/닉네임해제` | 패소자에게 적용된 닉네임 형벌을 즉시 해제합니다. | 관리자 |
| `/재판소설치` | 현재 채널에 재판소 메인 패널을 설치합니다. | 개발자 |
